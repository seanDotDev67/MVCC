# PHP MVC Learning Journey

> Understanding PHP MVC fundamentals by building a simple application from scratch.

## 📌 About This Project

This repository documents my journey in learning **PHP Model-View-Controller (MVC) architecture**.

Instead of immediately relying on frameworks like Laravel, I'm building a custom MVC application to understand how backend applications work behind the scenes.

My goal is to understand the fundamentals, write cleaner code, and develop the confidence to build applications independently.

## 🛠️ Technologies Used

- PHP
- MySQL
- PDO (PHP Data Objects)
- HTML5
- CSS3
- Bootstrap 5
- JavaScript
- XAMPP

## 🧠 My Learning Philosophy

I don't want to simply memorize code or copy implementations.

I want to understand:

- Why does this code exist?
- How does data move between the Model, View, and Controller?
- How does PHP process a request?
- How does the application communicate with the database?
- How do frameworks like Laravel implement these concepts?

Understanding the fundamentals first will help me become a better backend developer.

## 🎯 Final Goal

Build a functional PHP MVC application independently and understand how its architecture connects to modern frameworks, particularly Laravel.

**Learn the fundamentals. Understand the architecture. Build with confidence.**
